# Start here

This is an [Obsidian](https://obsidian.md/) vault that documents the
[Fix Tab Size](https://github.com/mnaoumov/obsidian-fix-tab-size/) plugin by demonstrating it.

Obsidian has an **Indent visual width** setting, and it honours it for real tab characters. It ignores
it for **spaces**: with **Indent using tabs** turned off, one level of indent is always **four** spaces,
however you configure the width. This plugin makes the space indent match the width you set.

> [!IMPORTANT]
>
> The plugin only does anything while **Indent using tabs** is OFF. If you indent with tabs, Obsidian
> already draws them at your configured width and there is nothing here for you.

## Your first minute

1. Open [01 Fix tab size](<./01 Fix tab size.md>) and press its **Indent with 8 spaces** button — it
   turns off **Indent using tabs** and sets the width, which both have to be right before anything is
   visible.
2. Put the cursor on a blank line and press `Tab`. Count the spaces: eight, matching the setting.
   Without the plugin it would be four.
3. Press **Indent with 2 spaces** and try again.
4. A last button restores Obsidian's defaults.
