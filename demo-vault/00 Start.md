Welcome to the [Fix Tab Size](https://github.com/mnaoumov/obsidian-fix-tab-size/) demo vault. This plugin makes the editor render real tab characters at the width you set in **Settings -> Editor -> Indent visual width**, instead of Obsidian's fixed built-in tab width.

**How to try it:** open the feature note below, look at its tab-indented sample, then change **Indent visual width** in the editor settings and watch the on-screen indentation follow along. Disable the plugin to see the tabs snap back to the fixed rendering.
