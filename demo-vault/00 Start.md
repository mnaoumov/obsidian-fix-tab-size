# Start here

This is an [Obsidian](https://obsidian.md/) vault that documents the
[Fix Tab Size](https://github.com/mnaoumov/obsidian-fix-tab-size/) plugin by demonstrating it.

Obsidian has an **Indent visual width** setting, but the editor ignores it for real tab characters: a
hard `Tab` is always drawn at Obsidian's own fixed width, however you configure it. So a file indented
with tabs looks one way in your editor and another way everywhere else. This plugin makes the editor
honour the width you set.

## Your first minute

1. Open [01 Fix tab size](<./01 Fix tab size.md>) and look at its tab-indented sample.
2. Change **Settings -> Editor -> Indent visual width** to something obvious, like 8.
3. Watch the sample's indentation follow along — with the plugin disabled it would not move.
